# PrismOS

Открытая веб-ОС (Web OS) с открытым исходным кодом.

![License](https://img.shields.io/badge/license-MIT-blue)
![Version](https://img.shields.io/badge/version-Classic%20cl--0910-green)

## О проекте

PrismOS — это веб-операционная система, работающая прямо в браузере.
Проект написан на HTML, CSS и JavaScript и распространяется под лицензией MIT.

## Возможности

- Рабочий стол в браузере
- Смена обоев
- Окна
- Меню Пуск
