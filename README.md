## О проекте

PrismOS — это веб-операционная система, работающая прямо в браузере.
Проект написан на HTML, CSS и JavaScript и распространяется под лицензией MIT.

Интерфейс в стиле Windows 10: панель задач с треем, лента в Проводнике,
двухколоночные Параметры, объёмные окна и загрузочный экран.

## Возможности

- Рабочий стол в браузере
- Панель задач в стиле Windows 10: Пуск, Поиск, закреплённые иконки, трей (Wi-Fi, звук, раскладка, часы, уведомления)
- Загрузочный экран с прогрессом и этапами загрузки
- Оконный менеджер: перетаскивание, сворачивание, разворот, закрытие
- Контекстное меню на рабочем столе (ПКМ)
- Свои модалки и уведомления вместо нативных `alert` / `confirm` / `prompt`
- Системные звуки: `startup`, `error`, `notify`
- Смена обоев и акцентного цвета
- Сохранение настроек, файловой системы и текста в `localStorage`

## Приложения

| Приложение | Описание |
|---|---|
| **Проводник** | Виртуальная ФС: дерево слева, таблица файлов справа, навигация, поиск, сортировка по колонкам |
| **Блокнот** | Текстовый редактор с сохранением в `localStorage` |
| **Терминал** | Команды: `help`, `ls`, `open <app>`, `clear`, `echo`, `about`, `error <text>`, `notify <text>` |
| **Калькулятор** | Базовые арифметические операции |
| **Параметры** | Двухколоночный макет в стиле Windows 10: Система, Персонализация, Устройства, Сеть, Обновление |
| **О системе** | Окно в стиле `winver` с версией, сборкой и именем пользователя |
