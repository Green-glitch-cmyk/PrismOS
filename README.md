## О проекте

PrismOS — это веб-операционная система, работающая прямо в браузере.
Проект написан на HTML, CSS и JavaScript и распространяется под лицензией MIT.

Интерфейс в стиле Metro с лёгкими 3D-эффектами: плавающий Dock, объёмные окна,
иконки с подъёмом при наведении.

## Возможности

- Рабочий стол в браузере
- Плавающий Dock с запуском и переключением приложений
- Оконный менеджер: перетаскивание, сворачивание, разворот, закрытие
- Контекстное меню на рабочем столе (ПКМ)
- Смена обоев и акцентного цвета
- Сохранение настроек и текста в `localStorage`
- Лёгкие 3D-эффекты интерфейса

## Приложения

| Приложение | Описание |
|---|---|
| **Проводник** | Виртуальная файловая система с навигацией |
| **Блокнот** | Текстовый редактор с сохранением в `localStorage` |
| **Терминал** | Команды: `help`, `ls`, `open <app>`, `clear`, `echo`, `about` |
| **Калькулятор** | Базовые арифметические операции |
| **Параметры** | Смена обоев и акцентного цвета |
| **О системе** | Информация о версии и сборке |
